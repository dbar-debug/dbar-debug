# PushStats-сервер

Пасивний моніторинг роутерів MikroTik: роутер сам надсилає статистику
кожні 5 хвилин (скрипт + scheduler встановлюються додатком автоматично),
сервер зберігає часові ряди, віддає їх додатку і шле сповіщення про
проблеми.

```
RouterOS (script + scheduler, /tool fetch POST)
        │
        ▼
POST /push  ──► SQLite (часові ряди, 14 днів)
        │
        ├─► GET /api/routers?token=…            — список + останні метрики
        ├─► GET /api/routers/{id}/history?…     — історія для графіків
        └─► алерти: CPU/пам'ять/диск ≥ порога, роутер офлайн
                    → лог + вебхук (ntfy.sh / Telegram / свій приймач)
```

## Запуск

### Docker (рекомендовано для сервера)

```bash
cd mikrotik/pushstats-server
docker-compose up -d
```

### Локально

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8080
```

Далі опублікуйте порт через ваш Nginx + Let's Encrypt (як для court-app),
щоб роутери надсилали статистику по HTTPS.

## Налаштування в додатку

1. Вкладка **PushStats** → налаштування: вкажіть URL сервера
   (напр. `https://ваш-домен:8443`) і згенеруйте токен.
2. **Встановити на роутер** → виберіть збережений роутер. Додаток через
   RouterOS API створить скрипт `mm-pushstats` і scheduler (кожні 5 хв)
   та одразу запустить перший пуш.
3. Картки роутерів з'являться у вкладці PushStats.

## Сповіщення

Задайте `ALERT_WEBHOOK_URL`. Найпростіший спосіб отримувати push на
iPhone без Apple Developer акаунта — застосунок [ntfy](https://ntfy.sh):
створіть топік і вкажіть `https://ntfy.sh/<ваш-секретний-топік>`.
Нативні APNs-push — окрема фаза (потрібен ключ Apple Developer).

## API

| Метод | Шлях | Опис |
|---|---|---|
| POST | `/push` | Прийом статистики від роутера (form-urlencoded) |
| GET | `/api/routers?token=` | Список роутерів з останніми метриками |
| GET | `/api/routers/{id}/history?token=&hours=24` | Історія метрик |
| GET | `/health` | Перевірка живості |

Автентифікація — спільний секретний `token` (генерується додатком):
роутер підписує ним кожен пуш, додаток — кожен запит читання. Роутери
різних токенів ізольовані один від одного, тож один сервер може
обслуговувати кілька користувачів/команд.
