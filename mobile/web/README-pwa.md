# PWA — «встановлення» на iPhone

Веб-версія додатку налаштована як PWA: додається на домашній екран
iPhone з іконкою і відкривається на повний екран без адресного рядка
Safari — виглядає й працює як застосунок.

## Що вже налаштовано (у git)

- `manifest.json` — назва «Судові справи», іконка, `display: standalone`,
  колір теми.
- `index.html` — iOS-мета-теги (`apple-mobile-web-app-capable` тощо) для
  повноекранного режиму.

Іконки (`web/icons/*.png`, `web/favicon.png`) Flutter згенерував локально
при `flutter create` — за замовчуванням це логотип Flutter. Щоб замінити
на свою іконку, покладіть свої PNG у `web/icons/` тих самих розмірів
(192, 512, і maskable-варіанти) перед збіркою.

## Як «встановити» на iPhone

1. Перезберіть і розгорніть веб зі свіжими manifest/index:
   - Windows (PowerShell, у `mobile/`): `flutter build web`
   - WSL: `~/court-app/server/deploy-web.sh`
2. На iPhone (Tailscale увімкнений) відкрийте в **Safari**:
   `http://100.77.97.16/`
3. Тапніть кнопку **Поділитися** (квадрат зі стрілкою вгору).
4. Виберіть **«На екран «Домівка»»** (Add to Home Screen).
5. Назва вже підставиться — «Судові справи». Тапніть **Додати**.

На домашньому екрані зʼявиться іконка. Відкриття з неї запускає додаток
на повний екран, як звичайний застосунок.

> ⚠️ Обовʼязково через **Safari** — Chrome на iOS не вміє додавати PWA
> на домашній екран.

## Оновлення

Після змін у коді: `flutter build web` (Windows) + `deploy-web.sh` (WSL).
PWA підхопить нову версію при наступному відкритті (може знадобитись
закрити й відкрити застосунок з домашнього екрана).
