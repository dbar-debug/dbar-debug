# Court App — мобільний клієнт

Flutter-додаток для пошуку судових справ (reyestr.court.gov.ua) та перегляду
особистих справ (cabinet.court.gov.ua) через бекенд з `../backend`.

КЕП-файл і пароль ніколи не залишають сервер — вони налаштовані в `.env`
бекенду (`KEP_FILE_PATH`, `KEP_PASSWORD`), а додаток лише викликає
`GET /cabinet/cases` без жодних облікових даних.

## Перший запуск (один раз)

У цьому репозиторії міститься лише Dart-код (`lib/`, `pubspec.yaml`).
Платформо-специфічні файли (`ios/`, `android/`) — це десятки автогенерованих
файлів з унікальними ID, які краще не тримати в git вручну. Згенеруйте їх
локально:

1. Встановіть [Flutter SDK](https://docs.flutter.dev/get-started/install)
   (Windows/macOS/Linux — розробляти можна з будь-якої ОС).
2. Перевірте оточення:
   ```bash
   flutter doctor
   ```
3. У цій папці (`mobile/`) згенеруйте платформи:
   ```bash
   flutter create --org com.dbartsukov --project-name court_app .
   ```
   Це додасть `ios/`, `android/`, `web/` та інші папки, НЕ чіпаючи вже
   наявні `lib/` і `pubspec.yaml`.
4. Встановіть залежності:
   ```bash
   flutter pub get
   ```

## Запуск під час розробки

Найшвидший спосіб перевірити, що все працює — без iPhone:

```bash
# У браузері (найпростіше на Windows/WSL)
flutter run -d chrome

# Або Android-емулятор / підключений Android-телефон
flutter run
```

Перед запуском відкрийте вкладку **Налаштування** в додатку і вкажіть
адресу вашого бекенду (наприклад `http://192.168.1.50:8000` для локальної
мережі, або `https://court-app.duckdns.org` після деплою з HTTPS).

⚠️ Якщо тестуєте на реальному Android-телефоні або в браузері з іншого
пристрою в тій самій Wi-Fi мережі — `localhost` не підійде, потрібна IP-адреса
комп'ютера, на якому запущено `uvicorn` (backend наразі слухає `0.0.0.0:8000`,
тобто вже приймає з'єднання з мережі).

## Запуск на iPhone

Збірка під iOS вимагає **Xcode**, який працює лише на macOS. Варіанти:

- **Є Mac** — встановіть Xcode, підключіть iPhone кабелем, `flutter run`.
- **Немає Mac** — хмарні CI-сервіси на кшталт
  [Codemagic](https://codemagic.io) (є безкоштовний тариф) можуть зібрати
  `.ipa` з цього репозиторію без власного Mac; встановлення на телефон —
  через TestFlight.

Поки Mac/CI не налаштовано, розробляти й тестувати логіку зручно через
`flutter run -d chrome` — весь UI та мережевий код однакові для всіх платформ.
